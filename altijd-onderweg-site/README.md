# Altijd Onderweg

Homepage en tweede pagina (vertrek).

- `index.html` – homepage
- `vertrek.html` – pagina waar "VERTREK ->" naartoe leidt
- `style.css` – vormgeving
- `script.js` – tekst op maat + pijltjes die rechts uit "VERTREK" schieten
- `assets/titel.svg` – de titel (vectortekening uit het ontwerp)

Online zetten via GitHub Pages: Settings -> Pages -> Deploy from a branch -> main / root.
